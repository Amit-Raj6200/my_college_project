# Credit Card Fraud Detection System

A comprehensive machine learning system for detecting fraudulent credit card transactions with a responsive web interface.

## 🚀 Features

- **Multiple ML Models**: Logistic Regression, Random Forest, XGBoost
- **Imbalanced Data Handling**: SMOTE oversampling technique
- **Real-time Prediction**: Instant fraud detection with probability scores
- **Bulk Processing**: Upload CSV files for batch prediction
- **Interactive Visualizations**: Explore data patterns and model performance
- **Responsive UI**: Mobile-friendly Streamlit interface

## 📋 Requirements

- Python 3.8+
- See `requirements.txt` for complete list of dependencies
